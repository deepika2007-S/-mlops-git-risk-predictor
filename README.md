# 📊 MLOps Git Repository Risk Assessment & Defect Predictor

An enterprise-grade, real-time MLOps pipeline designed to intercept source code modifications, evaluate structural complexity metrics, and compute developer defect probabilities utilizing a trained Machine Learning engine before production deployment.

## ⚡ Core Engine Capabilities
- **Real-Time Static Code Analysis:** Syntactically parses source files to compute structural metrics like control-flow nested loop depths dynamically.
- **Continuous ML Inference Pipeline:** Serves a trained Random Forest Classification model to score defect probabilities in real time.
- **Responsive Management Interface:** Built an active Streamlit analytical dashboard rendering live telemetry metrics and predictive warning flags.

## 🛠️ Infrastructure Tech Stack
- **Languages:** Python (Core Pipeline)
- **Machine Learning Infrastructure:** Scikit-Learn (Random Forest Engine), Joblib (Model Serialization)
- **Data Engineering:** Pandas, NumPy
- **Interactive UI Framework:** Streamlit Dashboard Architecture
